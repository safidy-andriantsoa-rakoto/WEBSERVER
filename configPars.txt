* Strict parsing :
	Tabulation at first?
	location => /[directory or file] (ex: /images)
	root => /[ (+) directory] (ex: /audio)
	[tmp] [one space] [tmp_content] (ex: servername myServername.com)

* Construct a location class to store : root, index, cgi

* Config file content :
	- Must have a location "/"
	- Must have root/location

Full example:

server1 {

	host localhost [string]
	port 2003 [string]
	server_names localhost login1.fr [container = n]
 	error_page 404 502 (list all code available) [container = n]
	size 200MB [string]

	redirect https://login2.fr permanent(or redirect) [container = 2; optionnel]

	location / {     [class ; obligatoire "/"]

		root ./site/dim
		index index.html [optionnel]
		method GET
	}

	location /images {

		root ./site/dim/images
		method GET POST DELETE
		autoindex on (directory listing if no index)
	}

	location .php { [a rechercher si un ou plusieurs]

		SCRIPT_FILENAME ./cgi-bin
		method GET POST
	}
}
